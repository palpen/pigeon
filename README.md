# Pigeon

A private file shelf for your devices and agents. Upload Markdown, plain text, images (PNG/JPEG/GIF/WebP/AVIF), and PDFs; read previews, search/filter, copy links, download, and delete. Create Markdown notes directly in the browser. Homepage refreshes every 15 seconds.

## Configuration

- App: https://your-host.your-tailnet.ts.net:8443
- Local: http://127.0.0.1:8787
- Owner: you@example.com via Tailscale Serve identity headers.
- Original files and SQLite metadata: `data/` in this project. Browser storage is not used for file persistence.
- Maximum upload: 50 MB per file; text preview limit: 5 MB.

Keep the host computer awake, online, and signed in. Devices must connect to Tailscale using the owner account. The app is bound to IPv4 loopback; Tailscale Serve provides private HTTPS. Do not expose it through another proxy that accepts forged Tailscale identity headers. Local processes can access the localhost app, consistent with trusting the host machine. No Funnel/public route is required.

## Agents

```sh
curl --fail-with-body \
  -H 'X-Pigeon-Request: 1' \
  -F 'file=@report.md' \
  https://your-host.your-tailnet.ts.net:8443/api/files
```

The JSON response contains `id`, `name`, `kind`, `size`, `created`, and an absolute `url`. Give the user that URL. Alternatively use `scripts/upload.sh /absolute/path/to/report.md`. Set `PIGEON_URL` to override its destination.

- `GET /api/files` returns `{ "files": [...] }` with relative viewer/download URLs.
- `GET /api/files/{id}` returns metadata.
- `GET /api/files/{id}/content` returns sanitized HTML and original text for text/Markdown.
- `GET /api/files/{id}/download` downloads the original.
- `DELETE /api/files/{id}` permanently deletes an item; send `X-Pigeon-Request: 1`.

One file per request. Duplicate names create separate entries. Agent devices signed into the owner account need no additional secret. For tagged agent devices (which have no user identity), configure a strong `AGENT_TOKEN` environment value and pass `Authorization: Bearer ...`; this grants full read/write/delete access and still requires network access. Tokens are optional and not generated by default. There is no public sharing.

## Run / maintain

Requires Node 24+ (built-in SQLite).

```sh
npm ci
OWNER_LOGIN='you@example.com' PUBLIC_URL='https://your-host.your-tailnet.ts.net:8443' npm start
npm test
```

`deploy/com.example.pigeon.plist.example` is a template: replace `/absolute/path/to/pigeon`, the Node executable path, owner login, and public URL before using it. Create the `data/` directory before starting the service. Once installed at `~/Library/LaunchAgents/com.example.pigeon.plist`, it restarts crashes and starts after login. Stop with `launchctl bootout gui/$(id -u)/com.example.pigeon`. Restart with `launchctl kickstart -k gui/$(id -u)/com.example.pigeon`. Serve route: `/Applications/Tailscale.app/Contents/MacOS/Tailscale serve --bg --https=8443 http://127.0.0.1:8787`.

For backup, stop the app and copy the entire `data/` folder, then restart it. Back up both metadata and blobs together; deletion has no undo. Keep this project folder at its installed path or update the LaunchAgent. Protect local backups as private data.

Markdown HTML is sanitized and served under a restrictive CSP. Remote embedded images are blocked to keep previews self-contained; to embed an uploaded image, use its `/api/files/{id}/raw` path. Relative images bundled alongside Markdown are not uploaded automatically. HTML/SVG and arbitrary file types are rejected. PDF preview depends on browser PDF support; Download is always available. HEIC images must be exported to JPEG/PNG first. File names/extensions determine preview type; this is private storage, not a malware scanner. No third-party fonts, analytics, or CDN assets are used.

Security/reference docs: https://tailscale.com/docs/features/tailscale-serve and https://marked.js.org/.

## Compatibility after renaming

Pigeon was originally called Relay. Existing installations can keep their original directory, service label, database filename (`relay.sqlite`), and HTTPS URL. The API accepts both `X-Pigeon-Request: 1` and the original `X-Relay-Request: 1`. The upload script accepts `PIGEON_URL`, with `RELAY_URL` as a fallback.

## Version control

Only application source, dependency lockfile, tests, scripts, and documentation belong in Git. Uploaded files, databases, logs, dependencies, and local environment settings are ignored. Git is not a backup of uploaded content; back up `data/` separately.
